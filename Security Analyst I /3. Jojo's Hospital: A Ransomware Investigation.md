# Incident Report
## Background
### Type of Incident: Ransomware
## Summary
Jojo's hospital had their files encrypted by ransomware from the ransomware group lock byte.
A ransomware note was found on the machine AMFB-MACHINE stating that if they did not receive 2 million dollars in bitcoin in the next 72 hours they would leak all the sensitive health information from the hospital. They also contacted patient's forcing them to send $10,000 or have their sensitive information such as social security number's leaked.  

An attacker logged into the device AMFB-MACHINE with the user andavis on 2024-05-20 00:00:00+00:0. A file lockbyte_ransomer.exe was found on AMFB-MACHINE renamed it to spread_ransomware.exe and it was then put on to the network share shared by the whole hospital so all devices can access it.
An exfiltration file was downloaded from  https://secure-health-access[.]com/tools/patient_data_exporter.exe on the device AMFB-MACHINE and was used to then grab all the current, archive and old patient records from \\jojos-hospital-server\important_data. It was then uploaded to the wesbite https://secure-health-access[.]com/upload.

The ransomware group seemed to have bought login info from the dark net to get into user accounts where they then ran malicous docx files which ran multiple commands such as setting up a cobaltstrike C2 server on the IP and port 93.238.22.122:50050. They then did some pivoting where they ran the scanner advanced-ip-scanner.exe on that machine to find any network data they could use. They found network diagrams and credentials on the network share they zipped and uploaded to the website https://nothing-to-see-here[.]net/upload.
